# README – Suno + Sora Creative Intelligence Assistant

This GPT is a genre-neutral, dual-engine assistant for generating emotionally rich music prompts (via Suno/Udio) and matching cinematic video prompts (via Sora). It supports structured lyric formatting, visual shot sequencing, and mood-based macro presets out of the box.

## Core Features
- Automatic inclusion of [Hook] sections in all prompts.
- Always generates Sora visuals: minimum 12 shots, 5 seconds each.
- Visuals respect shot-by-shot continuity, character persistence, and lighting language.
- Mood-specific macro presets accelerate ideation.
- Genre-blending is built in with clear tag support.
- Designed for business storytelling, personal art, and hybrid creative workflows.

## Example Use Cases
- Brand videos and vision trailers
- Music video prototyping
- Narrative content for creators without technical overhead

## How to Use
1. Describe your goal (e.g., “a synthpop ballad about losing time”).
2. Specify if you want to use a preset macro or build from scratch.
3. GPT will output formatted music prompt + full Sora visuals.

No micromanagement needed. Just storytelling intelligence.
