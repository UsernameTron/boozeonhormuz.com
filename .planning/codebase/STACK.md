# Technology Stack

**Analysis Date:** 2026-10-13

## Languages

**Primary:**
- TypeScript 6.0.3 supports Astro frontmatter, content schemas, browser modules and generated routes. The version is pinned in `package.json`; `tsconfig.json` extends `astro/tsconfigs/strict`; `src/content.config.ts` defines the publication schemas.
- Astro component syntax combines HTML templates, TypeScript frontmatter and scoped styles in `src/components/YouTubeEmbed.astro` and routes under `src/pages/`.

**Secondary:**
- JavaScript ES modules power build and validation scripts, including `scripts/generate-media.mjs`; `package.json` declares `type: module`.
- HTML and CSS support standalone visitor applications in `public/apps/` and the shared Tailwind entry in `src/styles/global.css`.
- Markdown and YAML store publication data loaded by `glob` and `file` in `src/content.config.ts`.
- YAML configures GitHub Actions in `.github/workflows/deploy.yml` and `.github/workflows/lighthouse.yml`.

## Runtime

**Environment:**
- The inspected login shell resolves Node.js v25.2.1. A non-login execution shell resolves `/opt/homebrew/opt/node@22/bin/node` v22.21.1. Neither context matches the prescribed Node 24 runtime in `.nvmrc` and both `.github/workflows/deploy.yml` and `.github/workflows/lighthouse.yml`. Use Node 24 when reproducing CI results; record the actual shell runtime with each local verification.
- `package.json` permits Node >=22.12.0; that minimum is broader than the project's Node 24 development and CI target.
- Production consists of static files generated by `astro.config.mjs`; no production Node application server or Astro adapter is configured.

**Package Manager:**
- Login-shell npm is 11.6.2. `package.json` has no `packageManager` version pin, and CI uses the npm bundled with its Node 24 setup.
- `package-lock.json` is present with lockfile format 3. Both CI workflows install with `npm ci`.
- Use exact dependency pins from `package.json` and retain `package-lock.json`, as required by `CLAUDE.md`.

## Frameworks

**Core:**
- Astro 6.4.2 provides static routing, components, build-time content loading and schema validation through `src/content.config.ts`; the lockfile resolves Vite 7.3.3.
- Tailwind CSS 4.2.0 and `@tailwindcss/vite` 4.2.0 provide styling through `src/styles/global.css` and the Vite plugin configured in `astro.config.mjs`.
- Astro's bundled schema facilities validate content in `src/content.config.ts`, including media source paths, references, orientations and publication status.

**Testing:**
- Node's built-in test runner executes `tests/unit/*.test.mjs` through `npm run test:unit` in `package.json`.
- Playwright Test 1.63.0 runs Chromium browser regressions from `tests/e2e/`; `playwright.config.ts` uses two workers, a 45-second test timeout and an independently started production preview server.
- Lighthouse CI 0.15.1 audits the built static artifact through `lighthouserc.json` and `.github/workflows/lighthouse.yml`; its configured mobile viewport is 390 by 844 and it collects three runs per route.

**Build/Dev:**
- `@astrojs/check` 0.9.9 plus TypeScript 6.0.3 perform source checks through `npm run check` in `package.json`.
- `npm run verify` in `package.json` sequences source checking, unit tests, disposable catalog fixtures, production build, media verification, output verification and browser tests.
- `scripts/generate-media.mjs` runs automatically through `predev` and `prebuild`; it produces responsive WebP variants and `src/lib/generated-media.json` using Sharp 0.34.5.
- `npm run dev`, `npm run build` and `npm run preview` invoke Astro directly from `package.json`.

## Key Dependencies

**Critical:**
- `@astrojs/sitemap` 3.7.3 generates sitemap output through the integration in `astro.config.mjs`.
- `astro-og-canvas` 0.11.1 generates static social images in `src/pages/open-graph/[...route].ts`; local TTF assets avoid build-time font downloads.
- `@astro-community/astro-embed-youtube` 0.5.10 supplies the lightweight YouTube facade in `src/components/YouTubeEmbed.astro`.
- `@fontsource-variable/fraunces` 5.2.9 and `@fontsource-variable/inter` 5.2.8 supply bundled typography, pinned in `package.json`.
- Sharp 0.34.5 handles additive responsive image generation in `scripts/generate-media.mjs`, preserving source image bytes while producing 320, 640, 960 and 1280-pixel candidates where source dimensions permit.

**Infrastructure:**
- GitHub Pages publishes `dist/` through `.github/workflows/deploy.yml`; `astro.config.mjs` sets the apex site URL `https://boozeonhormuz.com` with static output and no base prefix.
- GitHub Actions installs Node 24 and Chromium, retains the exact validated `dist/` artifact, audits that artifact, requires the release validation result, then deploys only for main-branch non-PR runs in `.github/workflows/deploy.yml`.
- A deployed-site smoke script runs through `scripts/smoke-site.mjs` as the final CI deployment step in `.github/workflows/deploy.yml`.

## Configuration

**Environment:**
- No build-time service credential is required by `astro.config.mjs` or the npm command definitions in `package.json`.
- `BOH_TEST_PORT` selects the browser test preview port in `playwright.config.ts`; its default is 4321. `CI` enables forbidden focused tests and one retry.
- `.github/workflows/lighthouse.yml` derives `CHROME_PATH` from Playwright's installed Chromium executable.
- `.github/workflows/deploy.yml` passes the GitHub Pages deployment URL through `DEPLOYED_URL` to `scripts/smoke-site.mjs`.

**Build:**
- `astro.config.mjs`: static output, apex domain, sitemap integration and Tailwind Vite plugin.
- `tsconfig.json`: strict Astro TypeScript preset, generated Astro types included and `dist/` excluded.
- `src/content.config.ts`: typed collection loaders, media references and publication constraints.
- `playwright.config.ts`: browser suite execution and production preview orchestration.
- `lighthouserc.json`: mobile audit routes, three-run collection and route-specific assertions.
- `.github/workflows/deploy.yml` and `.github/workflows/lighthouse.yml`: artifact reuse, release checks and Pages publication.
- Keep Tailwind 4.2.0 pinned until compatibility with the Astro Vite line is confirmed; `CLAUDE.md` records the Vite 8 incompatibility of Tailwind 4.3.x. The current `astro.config.mjs` retains an explicit plugin type cast.

## Platform Requirements

**Development:**
- Node 24 from `.nvmrc`, npm and a lockfile installation are the reproducible project baseline; inspected login and non-login shell contexts resolve Node 25.2.1 and 22.21.1 respectively.
- Chromium is required for `npm run test:e2e` and `npm run test:lighthouse`; `.github/workflows/deploy.yml` and `.github/workflows/lighthouse.yml` install it through Playwright.
- Native image processing is provided by Sharp in `scripts/generate-media.mjs`; responsive media is regenerated before development and build commands in `package.json`.

**Production:**
- Static GitHub Pages hosting serves the validated `dist/` artifact at the apex domain configured in `astro.config.mjs`; publication is gated by the release-check job in `.github/workflows/deploy.yml`.
- Visitor interaction executes in the browser; the generated site requires no deployed Node runtime, as determined by static output and absence of an adapter in `astro.config.mjs`.
