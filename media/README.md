# Large website video files

These six full-quality MP4 delivery copies are preserved in Git and served through the public `site-media-2026-10-19` GitHub Release. They are outside `public/` so the complete website fits GitHub Pages' 1 GB published-site limit. The creator's original source masters remain untouched outside this repository.

Website content records contain the immutable release download URLs. The existing native players and YouTube alternatives remain in use; no new player system, paid service or domain change is involved. All six uploaded assets matched the original delivery files' byte sizes and SHA-256 hashes before publication. Do not delete or replace release assets referenced by published pages.

Keep future large delivery files here and publish verified release assets before adding their URLs to the catalogue. The production output check rejects a Pages bundle larger than 1,000,000,000 bytes. Site counts, layout, framing, media quality and page addresses do not change when a delivery copy moves here.

GitHub downloads return a generic HTTP content type. `LocalVideo.astro` supplies an explicit `source type="video/mp4"` for these URLs so WebKit can play them. Preserve that format hint; verify actual playback and seeking when adding delivery assets.
